# Legendary Gym Design

Landing page premium para uma academia de alto desempenho, com visual forte, elegante e focado em conversão.

## Visão geral

Este projeto foi desenvolvido como uma landing page moderna para uma academia de luxo, destacando:

- marca premium e identidade visual forte
- apresentação de modalidades e diferenciais
- planos e benefícios
- depoimentos e provas sociais
- CTA de conversão para agendamento / matrícula
- layout responsivo e dinâmica de scroll

## Stack

- Next.js 16
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Lenis
- Recharts
- Radix UI

## Estrutura principal

- `src/App.tsx` — composição da landing page
- `src/components/` — seções do site
- `src/index.css` — tema global, estilos, layout e visual premium
- `src/lib/data.ts` — conteúdo estático do site
- `pages/` — rotas do Next.js

## Requisitos

- Node.js 18+
- npm

## Instalação

```bash

```

## Scripts

```bash

```
